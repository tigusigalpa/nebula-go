`request_contract_test.go` independently reads the pinned OpenAPI and exercises all **173 query parameters** through the public service methods and an in-memory HTTP transport. It checks enum values, numeric boundaries, required fields, invalid values, CSV/repeated arrays and UTC timestamps with fractional seconds. Both Agent methods are checked against the chat-body schema, including full message history and streaming mode.

`contract_test.go` validates every saved success fixture against its response schema and compares every JSON value with the actual typed service result. Complete synthetic responses cover all **750 response properties** across the 41 operation schemas, including fields absent from the saved fixtures. Additional cases cover nullable fields, empty arrays/maps, int64 values above 2^53, subsecond timestamps, HTTP metadata and unknown upstream fields retained in `Raw`. These are offline contract checks, not live API compatibility tests.
